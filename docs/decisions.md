# 사용자 결정 기록

Eddie(사용자)가 직접 고른 것만 모은다. 여기에 적힌 것은 **되돌리기 전에 반드시 다시 묻는다.**
규칙의 자세한 내용은 `CLAUDE.md`(지금 규칙), 왜 그렇게 됐는지는 `docs/claude-history.md`(날짜별 기록)에 있다.
결정이 새로 생기면 이 표 맨 위에 한 줄을 넣는다(같은 커밋에서 CLAUDE.md 해당 절도 고친다).

## 함께 일하는 방식

- **화면이 바뀌는 일은 시안(캡처)을 먼저 보여 주고 고르게 한다.** 선택지가 있으면 A·B 안을 나란히 둔다.
  Eddie 가 고른 안에는 'A안'·'2번' 같은 이름을 붙여 이 표에 남긴다.
- **결과는 전후 캡처로 보여 준다** — 라이트·네이비·다크 세 테마, 1280·1440·1680px. 캡처는 프로젝트 파일
  `ui-polish-N/` 같은 주제 폴더에 둔다.
- **설명은 쉬운 한국어로.** 코딩 배경이 없으므로 용어 대신 '무엇이 보이고 왜 바뀌었는지'를 적는다.
  공감보다 사실 확인이 먼저다 — 요청이 사실과 다르면 근거를 들어 먼저 말한다.
- **같은 숫자를 두 번 보여 주지 않는다.** 중복 칸·중복 카드는 지우는 쪽이 기본이다(적립식 '월 환산' 칸, 세금 카드 합치기).
- **병합·배포는 Eddie 가 말할 때만.** PR 을 열고 CI 를 지켜보되, 병합은 'PR 머지하고 배포해줘' 같은 요청이 있어야 한다.
- 화면을 고치다 발견한 다른 버그는 같은 PR 에서 고치고, 고쳤다는 사실을 따로 알린다.
