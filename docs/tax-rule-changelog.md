# 세금·증여 규칙 변경 이력

이 문서는 `tax-rules.js`의 사람 검토 기록입니다. 자동 점검은 공식 페이지의 접속 가능 여부와 핵심 문구 변화를 찾지만, 세율·공제액을 자동 변경하지 않습니다.

## 갱신 절차

1. GitHub Issue 또는 검토기한 알림이 생기면 법제처 국가법령정보센터와 국세청 원문을 직접 대조합니다.
2. 적용일·지급일·거주자 요건·계좌 자격·지방세 포함 여부까지 확인합니다.
3. `values`, `disclosures.assumptions`, `disclosures.exclusions`, 공식 출처와 확인 문구를 함께 수정합니다.
4. 활성 규칙의 `id`, 최상위 `manifestVersion`, `verifiedAt`, `nextReviewAt`을 함께 올립니다. 다음 사람 검토는 최대 31일 이내로 잡습니다.
5. 이 문서에 무엇이 바뀌었고 무엇을 계산에서 제외했는지 적습니다.
6. `npm run check:tax-rules`, `npm run check:tax-rules:remote`, `npm test`를 모두 통과시킵니다.

- 적용 대상: 대한민국, 2026년 계산 참고값
- 다음 사람 검토: 2026-10-31
- **값 변경 없음.** `values`·`disclosures`·공식 출처 목록은 2026.3 과 같고, 검토일·다음 검토일·버전만 올렸다.
- 공식 출처 대조: `check-tax-rule-sources.mjs --network` 로 17곳 모두 정상, 변경 의심 0. 대조한 페이지는 현행 조문이다(예: 소득세법 제103조 [시행 2026. 7. 1.] [법률 제21221호, 2025. 12. 23., 일부개정] — 기본공제 연 250만원 그대로).
  - 점검 환경 메모: 이번 검토 환경은 `www.law.go.kr` 접속이 막혀 있어 같은 경로를 `law.go.kr` 로 받아 대조했고, Node 내장 fetch 가 환경 프록시를 쓰도록 `NODE_USE_ENV_PROXY=1` 로 실행했다. 저장소의 출처 URL·점검 스크립트는 바꾸지 않았다.
- 2차 자료 교차 확인: 2026 증권거래세(KOSPI 0.05% + 농특세 0.15%, KOSDAQ 0.20%), 해외주식 기본공제 250만원·22%, 국내시장복귀계좌(RIA) 특례(2026-08-01~12-31 양도분, 앱은 계산 제외로 공시)가 현재 값·공시와 일치.
- 2026-08-03 정부 세제개편안(생산적금융 ISA 신설, 청년형 ISA, 일반 ISA 계약기간 최대 5년·납입한도 이월 폐지 등)은 국회 통과 전이고 2027년 이후 적용 예정이라 2026 값에 반영하지 않는다. 2027 연도는 계속 '미지원(미검증)'으로 표시된다.

## kr-tax-gift-2026.3 — 2026-08-31 검토

- 적용 대상: 대한민국, 2026년 계산 참고값
- 다음 사람 검토: 2026-09-30
- 해외주식 일반 사례: 주식 양도소득 기본공제 250만원, 국세 20% + 개인지방소득세 2%를 합친 22%
- 국내 장내 매도 부담: KOSPI 증권거래세 0.05% + 농어촌특별세 0.15% = 0.20%, KOSDAQ 0.20%. 양도세 참고 합계에는 더하지 않음
- 일반 국내 배당 단순 원천징수: 국세 14% + 개인지방소득세 1.4% = 15.4%
- ISA: 일반형 200만원·서민/농어민형 400만원, 초과분 국세 9% + 지방세 0.9%. 법정 한도는 매년이 아니라 계좌 유지기간 전체 최종 순소득에 적용되므로 앱 계산은 연간 현금흐름 근사로만 표시
- 증여재산공제: 배우자 6억원, 직계존속 성년 5천만원·미성년 2천만원, 직계비속 5천만원, 기타 친족 1천만원. 공제 사용액과 동일 증여자 과세가액 합산 규칙을 분리해 안내
- 혼인·출산 추가공제: 직계존속 증여, 수증자 1인 합계 1억원. 혼인 신고일 전후 2년과 출생·입양일 이후 2년을 구분해 제외 항목으로 안내
- 유기정기금: 시행규칙상 연 3%를 적용하되 앱은 월말 동일액 납입으로 근사한다고 명시
- 2026년 고배당기업 배당 분리과세와 국내시장복귀계좌 특례는 기업·신청·계좌·재투자 요건을 자동 판정할 수 없어 계산에서 제외
- 2025-03-14 기타 친족 범위 변경(6촌 혈족·4촌 인척 → 4촌 혈족·3촌 인척)을 역사 규칙 주의사항에 반영
