# 세금·증여 규칙 변경 이력

이 문서는 `tax-rules.js`의 사람 검토 기록입니다. 자동 점검은 공식 페이지의 접속 가능 여부와 핵심 문구 변화를 찾지만, 세율·공제액을 자동 변경하지 않습니다.

## 갱신 절차

1. GitHub Issue 또는 검토기한 알림이 생기면 법제처 국가법령정보센터와 국세청 원문을 직접 대조합니다.
2. 적용일·지급일·거주자 요건·계좌 자격·지방세 포함 여부까지 확인합니다.
3. `values`, `disclosures.assumptions`, `disclosures.exclusions`, 공식 출처와 확인 문구를 함께 수정합니다.
4. 활성 규칙의 `id`, 최상위 `manifestVersion`, `verifiedAt`, `nextReviewAt`을 함께 올립니다. 다음 사람 검토는 최대 31일 이내로 잡습니다.
5. 이 문서에 무엇이 바뀌었고 무엇을 계산에서 제외했는지 적습니다.
6. `npm run check:tax-rules`, `npm run check:tax-rules:remote`, `npm test`를 모두 통과시킵니다.
