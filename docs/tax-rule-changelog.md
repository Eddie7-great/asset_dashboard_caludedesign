# 세금·증여 규칙 변경 이력

이 문서는 `tax-rules.js`의 사람 검토 기록입니다. 자동 점검은 공식 페이지의 접속 가능 여부와 핵심 문구 변화를 찾지만, 세율·공제액을 자동 변경하지 않습니다.

## 갱신 절차

1. GitHub Issue 또는 검토기한 알림이 생기면 법제처 국가법령정보센터와 국세청 원문을 직접 대조합니다.
2. 적용일·지급일·거주자 요건·계좌 자격·지방세 포함 여부까지 확인합니다.
3. `values`, `disclosures.assumptions`, `disclosures.exclusions`, 공식 출처와 확인 문구를 함께 수정합니다.
4. 활성 규칙의 `id`, 최상위 `manifestVersion`, `verifiedAt`, `nextReviewAt`을 함께 올립니다. 다음 사람 검토는 최대 31일 이내로 잡습니다.
5. 이 문서에 무엇이 바뀌었고 무엇을 계산에서 제외했는지 적습니다.
6. `npm run check:tax-rules`, `npm run check:tax-rules:remote`, `npm test`를 모두 통과시킵니다.

## kr-tax-gift-2026.6 — 2026-11-23 추가(연금계좌 세액공제 한도)

- 적용 대상: 대한민국, 2026년 계산 참고값
- 다음 사람 검토: 2026-11-28 (2026.5 의 검토 기한 그대로 — 검토일은 올리지 않았다)
- **값 추가:** 세금 화면의 '연말 절세 체크' 카드용 `pensionCredit` — 연금저축 세액공제 대상 납입 한도 연 600만원(`pensionSavingsCapKrw`), 연금저축 + 퇴직연금(IRP 등) 합산 연 900만원(`combinedCapKrw`). 공식 출처 `pension-account-tax-credit`(소득세법 제59조의3)과 공시 `taxSaving` 을 함께 추가했다. 기존 값은 바뀌지 않았다.
- 계산에서 제외(공시에 적음): 세액공제율(총급여·종합소득에 따라 다름)과 환급액, ISA 납입 한도·만기 전환 추가 공제, 50세 이상 한시 한도, 연금 수령 시 과세. 앱은 사람이 적은 올해 납입액이 한도를 얼마나 채웠는지만 보여 준다.
- **원문 대조 미완료 — 사람 확인 필요.** 이 작업 환경에서는 `law.go.kr`·`www.law.go.kr` 모두 프록시가 403 으로 막아 조문 원문을 받지 못했다. 600만원·900만원은 2차 자료(국세청 안내를 옮긴 기사·금융사 안내)로만 교차 확인했다. 다음 `tax-rule-watch` 예약 점검 또는 `npm run check:tax-rules:remote` 가 새 출처의 기대 문구(`제59조의3`·`600만원`·`900만원`)를 확인해야 하며, 어긋나면 이 값을 고치기 전까지 카드를 믿지 않는다.
- ISA 납입 한도 확대(연 4천만원 등) 보도는 2027년 이후 적용 예정·국회 통과 전이라 반영하지 않았고, 그래서 카드의 ISA 칸은 한도 판정 없이 납입액만 적는다.

## kr-tax-gift-2026.5 — 2026-10-28 검토

- 적용 대상: 대한민국, 2026년 계산 참고값
- 다음 사람 검토: 2026-11-28 (검토일로부터 31일 이내)
- **값 변경 없음.** `values`·`disclosures`·공식 출처 목록은 2026.4 와 같고, 검토일·다음 검토일·버전만 올렸다.
- 공식 출처 대조: 17곳 모두 기대 문구 유지, 변경 의심 0.
  - `check-tax-rule-sources.mjs --network` 로 16곳 정상. 남은 1곳(소득세법 제104조, `income-tax-stock-rate`)은 응답에 약 31초가 걸려 점검기의 20초 제한을 넘겼으므로 같은 주소를 직접 받아 대조했다 — `제104조`·`100분의 20` 그대로, [시행 2026. 1. 1.] [법률 제21221호, 2025. 12. 23., 일부개정]으로 지난 검토와 같은 개정 차수다.
  - 같은 날 GitHub 예약 점검(tax-rule-watch)도 17곳 모두 정상이었다.
  - 점검 환경 메모: 2026.4 검토 때와 같이 `www.law.go.kr` 이 막혀 같은 경로를 `law.go.kr` 로 받아 대조했고 `NODE_USE_ENV_PROXY=1` 로 실행했다. 저장소의 출처 URL·점검 스크립트는 바꾸지 않았다.
- 2차 자료 교차 확인: 해외주식 기본공제 250만원·22%, 증여재산공제(배우자 6억원, 직계존속 성년 5천만원·미성년 2천만원), 혼인·출산 추가공제 1억원이 현재 값과 일치. 2026년 값을 바꾸는 개정 근거는 찾지 못했다.
- 2026-08 정부 세제개편안은 여전히 국회 통과 전이고 2027년 이후 적용 예정이라 반영하지 않는다. 연말 국회 통과 뒤 2027 규칙 세트를 따로 추가해야 한다(그 전까지 2027 연도는 '미지원(미검증)'으로 표시된다).

## kr-tax-gift-2026.3 — 2026-08-31 검토

- 적용 대상: 대한민국, 2026년 계산 참고값
- 다음 사람 검토: 2026-09-30
- 해외주식 일반 사례: 주식 양도소득 기본공제 250만원, 국세 20% + 개인지방소득세 2%를 합친 22%
- 국내 장내 매도 부담: KOSPI 증권거래세 0.05% + 농어촌특별세 0.15% = 0.20%, KOSDAQ 0.20%. 양도세 참고 합계에는 더하지 않음
- 일반 국내 배당 단순 원천징수: 국세 14% + 개인지방소득세 1.4% = 15.4%
- ISA: 일반형 200만원·서민/농어민형 400만원, 초과분 국세 9% + 지방세 0.9%. 법정 한도는 매년이 아니라 계좌 유지기간 전체 최종 순소득에 적용되므로 앱 계산은 연간 현금흐름 근사로만 표시
- 증여재산공제: 배우자 6억원, 직계존속 성년 5천만원·미성년 2천만원, 직계비속 5천만원, 기타 친족 1천만원. 공제 사용액과 동일 증여자 과세가액 합산 규칙을 분리해 안내

- 유기정기금: 시행규칙상 연 3%를 적용하되 앱은 월말 동일액 납입으로 근사한다고 명시
